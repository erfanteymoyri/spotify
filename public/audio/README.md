# فایل‌های صوتی نمونه (داده‌ی seed بک‌اند)

این فایل‌ها **دیگر مستقیماً توسط فرانت‌اند سرو نمی‌شوند.** از فاز دوم، تمام مدیا از
سمت بک‌اند و از روی MinIO سرو می‌شود و آدرس آن‌ها در پاسخ API (`audioUrl` و `coverUrl`)
می‌آید.

نقش فعلی این پوشه فقط تغذیه‌ی دستور seed بک‌اند است:

- در اجرای محلی، `python manage.py seed_demo` این پوشه را در مسیر
  `../spotify-frontend/public` پیدا می‌کند.
- در داکر، `docker-compose.yml` همین پوشه را به‌صورت read-only روی `/seed-media`
  در کانتینر بک‌اند mount می‌کند.
- اگر پوشه در دسترس نباشد، seed به‌صورت خودکار یک فایل صوتی و کاور جایگزین تولید
  می‌کند تا آهنگ‌ها همچنان قابل پخش باشند.

| نام فایل | اثر |
|---|---|
| `track-1.mp3` | همایون شجریان — ایران من |
| `track-2.mp3` | همایون شجریان — خوب شد |
| `track-3.mp3` | همایون شجریان — چرا رفتی |
| `track-4.mp3` | همایون شجریان — کولی |
| `track-5.mp3` | حسن عطایی — الصبوح الصبوح |
| `track-6.mp3` | حسین طاهری — خانه ما نجف |
| `track-7.mp3` | سید رضا نریمانی — کریم |
| `track-8.mp3` | علی اکبر حائری — اختصاصا از نجف |
| `track-9.mp3` | حسن عطایی — حسین اومده |
| `track-10.mp3` | محسن محمدی‌پناه — باید برخاست |

کاور مولودی‌ها نیز در `public/cover/` (cover5 تا cover10) قرار دارد.
